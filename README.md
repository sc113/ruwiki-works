# ruwiki works

Bot tasks for Russian Wikipedia with a web interface for monitoring, reports and admin controls.

Ботозадачи для обслуживания русской Википедии. Веб-интерфейс помогает контролировать обработку, управлять запусками и просматривать отчёты. Публично доступны состояние задач, сроки обработки, списки ручных исправлений и история запусков. Панель admin добавляет управление, настройки и полные диагностические журналы; доступ подтверждается через Wikimedia OAuth.

## Задачи

| Раздел | Действия |
| --- | --- |
| Обсуждения категорий | Зачёркивание завершённых обсуждений, обновление сводной страницы и проверка оформления номинаций |
| Шаблоны о проблемах | Расстановка дат; замена параметров RQ на шаблоны; разворачивание RQ с одним шаблоном |
| Плохие и грубые переводы | Добавление языка и оригинала из истории создания статьи или страницы обсуждения |
| Шаблоны разделов | Замена «Пустой раздел» на «Дополнить раздел» при наличии содержимого и обратная замена для пустых разделов |

Все восемь действий выполняются последовательно через общую очередь. Отдельный монитор отслеживает изменения и обновляет публичные счётчики. По умолчанию ОБКАТ проверяется каждые 5 минут и обрабатывается через 15 минут после последней правки; в конце месяца включается форматирование. Остальные источники проверяются каждые 6 часов, обработка шаблонов запускается в 03:00, переводов и разделов — в 04:00 МСК. Расписания изменяются в панели admin.

Отметки обработанных и пропущенных статей сохраняются между запусками. Доступны повторная проверка отдельных статей, проход с нуля, пауза и остановка задач. Запись через MediaWiki API учитывает версии страниц, ограничения частоты и ошибки API.

## Устройство

- Flask: HTML-интерфейс, отчёты, история запусков и Wikimedia OAuth.
- SQLAlchemy: SQLite для локальной работы, MariaDB ToolsDB для Toolforge.
- Общий исполнитель и независимый монитор; настройки, очередь и журналы хранятся в базе.
- MediaWiki API для чтения и записи.

## Локальный запуск

Python 3.11 или новее:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
Copy-Item .env.example .env
.venv\Scripts\python.exe -m toolforge_app init-db
.venv\Scripts\python.exe -m toolforge_app serve
```

Сайт доступен по адресу `http://127.0.0.1:5000/`. Настройки берутся из переменных окружения или приватного `.env`. По умолчанию запись в Википедию выключена, доступ admin не назначен. Сайт можно просматривать без фоновых процессов.

Исполнитель и монитор запускаются в отдельных терминалах:

```powershell
.venv\Scripts\python.exe -m toolforge_app worker --task all
.venv\Scripts\python.exe -m toolforge_app worker --task monitor
```

Проверки:

```powershell
.venv\Scripts\python.exe -m pytest -q
```
