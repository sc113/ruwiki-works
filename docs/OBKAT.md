# Обсуждения категорий

Действие `obkat` обрабатывает месячные страницы «Википедия:Обсуждение категорий» и обновляет страницу «Текущие обсуждения». Начальный месяц задаётся в конфигурации. Все отчёты и журналы этого действия публичны.

## Очередь и расписание

Монитор каждые **5 минут** читает RecentChanges с перекрытием по времени и сверяет текущие ревизии месячных страниц. Это позволяет находить изменения при задержке ленты и восстанавливать задания после перезапуска. Для изменённой страницы сохраняется одно задание со сроком **15 минут после последней правки**. Новая правка переносит срок. Перед обработкой исполнитель заново получает актуальную версию: свежая правка откладывает задание до окончания паузы.

Поиск и автоматическое выполнение включаются отдельно. Выключенный исполнитель сохраняет задания, но не выполняет их по расписанию; явный ручной запуск может выполняться. Обзор показывает состояние поиска, ближайшую проверку и причину ожидания готовой задачи.

В последний день месяца в **23:30 МСК** назначается проход всех месячных страниц с форматированием пробелов. Страницы со свежими правками ждут окончания паузы. Частоту поиска, задержку и время месячного прохода admin редактирует через общий редактор расписания.

Все действия проекта используют последовательный исполнитель. Если он занят, готовая страница ждёт своей очереди. Собственная сохранённая версия бота не вызывает повторную обработку.

## Обработка текста

`formatter.py` зачёркивает завершённые номинации. В режиме форматирования дополнительно упорядочивает пробелы и пустые строки. Преобразование принимает текст страницы и флаг `spacing`; повторная обработка уже приведённого к нужному виду текста не создаёт изменений.

`analyzer.py` проверяет вложенность заголовков, расположение итогов и служебных разделов, порядок дат, повторы номинаций, пустые номинации и теги зачёркивания. Структурные проблемы сопровождаются ссылкой на номинацию и инструкцией для ручного исправления.

`table.py` собирает сводную страницу открытых обсуждений из проверенных месячных страниц. Открытые номинации и номинации с подитогами сохраняются в списке. Публикация сводной страницы разрешена после полной первичной синхронизации.

## Отчёт и журналы

- **Проблемы** — нарушения оформления, место на странице и способ исправления.
- **Открытые номинации** — построчный список, отдельная отметка для подитогов.
- **Лог** — история запусков со ссылками на журналы, события и различия текста.

Даты обнаружения и подтверждения отражают фактические проверки. В режиме без записи отчёт строится по полученному тексту Википедии; предлагаемые изменения показываются отдельно в журнале. После сохранения анализируется сохранённая версия.

Запись проверяет базовую ревизию и ограничения редактирования. ОБКАТ использует флаг бота и явно передаёт `notminor=1`. Конфликт сохраняет правку участника, а задание остаётся в очереди с задержкой повторной попытки. Подробности: [обработка ошибок API](API_SAFETY.md).

## Запуск

Исполнитель и монитор запускаются в отдельных процессах:

```bash
python -m toolforge_app worker --task all
python -m toolforge_app worker --task monitor
```

Постановка ручного задания из CLI:

```bash
python -m toolforge_app run-obkat
python -m toolforge_app run-obkat --spacing
```

Для выполнения поставленного задания должен работать исполнитель. Те же действия доступны admin на странице ОБКАТ.
