# Журналы и хранение

История запусков, краткие результаты страниц, идентификаторы сохранённых правок и данные для статистики сохраняются постоянно. Статистика рассчитывается по итогам запусков и сохранённым событиям правок, включая уникальные страницы, переходы через полночь и количество операций с шаблонами.

Полные диагностические журналы, тексты сравнения и снимки отчётов хранятся 90 дней после завершения запуска. Срок задаётся переменной `TOOLFORGE_LOG_RETENTION_DAYS` (1–3650). После этого остаётся тот же публичный список результатов страниц; полный снимок отчёта и текст сводки становятся недоступны. Страница запуска сообщает об истечении срока хранения диагностических данных.

Большие поля отчётов, снимки сводной страницы и подробные журналы завершённых запусков сжимаются zlib и сохраняются по SHA-256 содержимого. Одинаковые списки используются несколькими запусками. Приложение восстанавливает исходные данные при открытии или экспорте запуска. Обзор и история читают краткие записи; публичный журнал и статистика используют сохранённые краткие результаты страниц. Общий журнал admin загружает подробные события без полных снимков отчётов.

Обслуживание проверяется исполнителем раз в час, даже если автоматические ботозадачи выключены. За один проход обрабатывается до 100 завершённых запусков; при наличии очереди следующие порции выполняются с интервалом 30 секунд. Изменения каждой записи атомарны. Незавершённые запуски не очищаются. Неиспользуемые снимки удаляются после проверки ссылок на них. Ошибки обслуживания создают уведомление и повторяются автоматически, не останавливая ботозадачи.

Отметки `article_checks`, текущие источники, списки «пропустить», проблемы, настройки, очередь и учётные данные не входят в очистку журналов. Они сохраняются отдельно.

В настройках профиля доступен блок «Журналы и хранение»: срок хранения, размер базы, журналов и сжатых снимков, дата проверки. Уведомление о размере базы возникает от 5 ГиБ. Выделенное InnoDB место после очистки может не уменьшиться сразу; оно используется повторно для новых записей.

Обслуживание можно выполнить вручную в окружении приложения:

```sh
python -m toolforge_app maintain-storage --batch-size 100
```

Команда выполняет одну порцию и выводит количества обработанных и оставшихся записей. Она не включает запись в Википедию и не меняет расписания.
