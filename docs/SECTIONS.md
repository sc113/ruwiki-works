# Шаблоны разделов

Раздел `/processors/sections` содержит два независимых действия:

| Действие | Условие замены |
| --- | --- |
| `sections-empty-to-fill` | «Пустой раздел» → «Дополнить раздел», если в разделе или подразделах есть содержимое |
| `sections-fill-to-empty` | «Дополнить раздел» → «Пустой раздел», если раздел и все подразделы пусты |

Монитор ищет включения шаблонов каждые **6 часов**. Обработка назначается на **04:00 МСК**, последовательно через общую очередь. Время каждого действия редактируется рядом с кнопками управления.

## Отбор и отметки

Источники — включения выбранного шаблона и его перенаправлений в пространство статей (0). Статьи-перенаправления не редактируются. Монитор получает список без чтения текстов статей и без правок.

«К обработке» показывает ещё не проверенные названия. Успешные результаты и отсутствие нужной замены сохраняются в `article_checks`, отдельно для каждого направления. Отметка привязана к названию; последующие правки статьи автоматически её не снимают. Технические ошибки и конфликты сохранения не создают постоянный пропуск.

Кнопка admin **«С нуля»** сбрасывает отметки выбранного действия при начале полного прохода. История сохраняется, продолжение после паузы не очищает прогресс повторно. В режиме без записи отметки обходятся, но не удаляются; предложения правок не пополняют постоянный учёт.

## Проверка содержимого

Пустыми считаются разделы, содержащие только пробелы, комментарии, неразрывные пробелы, файлы, категории, сноски `<ref>` и настроенные служебные шаблоны. Заголовок сам по себе не считается содержимым. Текст дочернего раздела делает родительский раздел непустым; соседние разделы проверяются независимо. Обычные ссылки, неизвестные шаблоны, таблицы и видимый текст считаются содержимым.

Меняется только имя непосредственно включённого шаблона. Параметры, даты, пробелы вокруг имени и остальная разметка сохраняются. Примеры в комментариях, nowiki, заголовках и вложенных шаблонах не заменяются. Все подходящие вхождения проверяются по исходному содержимому раздела, до изменения текста.

Если прямое содержимое раздела включает оба маркера, этот раздел остаётся без изменений и попадает в ручные проблемы. Остальные разделы статьи могут обрабатываться.

## Параметры admin

- Искомый шаблон и шаблон замены.
- Шаблоны, которые не считаются содержимым раздела.
- Автосохранение и пропуск уже проверенных статей (`resume`).
- Лимит статей за запуск и лимит результатов на имя шаблона; 0 означает отсутствие ограничения.
- Сроки кеширования списка статей и перенаправлений.
- Подробная диагностика разделов, частота поиска и время ежедневного запуска.

Перенаправления читаются автоматически и показываются с отступами под основным шаблоном. Их кеш по умолчанию действует **14 дней**; 0 отключает его. Кнопка «Обновить перенаправления» передаёт запрос монитору.

Кеш списка статей по умолчанию отключён: каждый поиск получает свежие включения. Ручное обновление и «С нуля» обходят кеш. Дата поиска отражает получение данных из Википедии. Ограниченный лимитом список помечается как неполный. История ревизий для определения пустоты не используется.

## Отчёты и журналы

Публичный журнал показывает обработанные статьи с кратким результатом. Для сохранённых правок указаны исходный и новый шаблон, раздел и причина замены. Admin видит параметры запуска, диагностику, пропуски, ошибки и текст до/после. Общая история содержит длительность, итоги обработки и изменение числа проблем и пропусков.

## Запуск

```bash
python -m toolforge_app refresh-sections
python -m toolforge_app worker --task all
python -m toolforge_app worker --task monitor
```

`refresh-sections` только обновляет списки. Исполнитель и монитор запускаются отдельными процессами; обе обработки разделов используют общий слот и порядок очереди.
